# DLOG workflow coverage

Reference: the user-supplied **DLOG User Manual v1.0 (2026)**, 58 physical PDF pages. Page numbers below refer to those PDF pages. The PDF stays outside the repository. This inventories workflows; it does not claim matching proprietary algorithms, appearance or unspecified file dialects.

**Shipped** means the workflow is implemented within its documented limits. **Partial** identifies specific remaining behavior. **Needs profile** requires a recipient format/schema and validation sample. Qualification is separate from implementation status; the new studies do not inherit the older parser's large-file performance qualification.

## Product organization

Keep the library and selected population central. Table, charts, wafers and records remain the daily workflow; the compact Tools selector opens specialized studies, source authoring and report exports. Preserve original identity in every pick. Put methods and long provenance behind disclosures; avoid a copied desktop ribbon or every optional control remaining permanently visible.

The manual does not specify PAT formulas, GDBN/CD connectivity/weighting, R&R estimators, PVT assignment, quartile conventions, repeat pairing or downstream wafer dialects. Every open method retains its own version and recipe. Preview decisions and derived STDF copies remain distinguishable from retained source data.
