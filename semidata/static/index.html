ENGINEER GUIDE

A useful first session

Make a small, repeatable evaluation before working with a larger production dataset.

Open complete guide ↗
01

Build your library

Load the bundled examples or generate STDF files at STDF.io. Paste the downloaded files’ full local paths into the import form. Select datasets to define the population.

02

Explore a measurement

Search for a test, compare its distribution and lot statistics, and inspect the ordered measurement plot. All histogram bins and summary statistics use the full valid population.

03

Evaluate PAT

Choose mean/SD or median/MAD limits, set k, and preview flagged devices. Use a separate reference dataset when the limits should be learned from a different population.

04

Keep the evidence

Save a screening experiment to preserve its recipe, source hashes, limits, and result. Open Saved runs to retrieve the result or export the complete flagged-device CSV.

Know this release’s boundaries

This evaluation release analyzes scalar PTR measurements. It does not provide production sign-off, MPR/FTR analytics, wafer-map screening, or automated AEC compliance. Current-attempt handling applies within each file. PAT requires enough eligible reference measurements and nonzero spread; read the calculation reference before interpreting limits.

The library lists the most recent 200 datasets and runs. Analysis accepts up to 20 datasets and 500,000 measurement rows. Ordered plots display at most 800 points; PAT previews display at most 1,000 flagged rows, while saved CSV exports retain all flags.
